Comandos básicos de Git
git --version

Definición: Muestra la versión de Git instalada en el sistema.

Ejemplo:
------------------------------------------------
git --version

git init

Definición: Inicializa un nuevo repositorio Git en la carpeta actual.

Ejemplo:

git init
------------------------------------------------
git add

Definición: Agrega archivos o cambios al área de preparación (staging).

Ejemplo:

git add .

Agrega todos los archivos y cambios del proyecto.
------------------------------------------------
git commit

Definición: Registra los cambios realizados en el repositorio con un mensaje descriptivo.

Ejemplo:

git commit -m "Primer commit"
------------------------------------------------
git status

Definición: Muestra el estado actual del repositorio, indicando archivos modificados, agregados o pendientes de seguimiento.

Ejemplo:

git status
------------------------------------------------

Flujo típico de trabajo en Git

git init 
git add . 
git commit -m "Primer commit" 
git status
